# Contributing to Devora 🚀

Thank you for your interest in contributing to Devora.

We welcome contributions of all kinds, including bug fixes, feature improvements, UI/UX enhancements, documentation updates, and performance optimizations.

## Getting Started

### 1. Fork the Repository

Create a fork of the repository on GitHub.

### 2. Clone Your Fork

```bash
git clone https://github.com/55Lavkush555/devora.git
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env.local` file and add the required environment variables.

```env
MONGODB_URI=
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=
CLERK_SECRET_KEY=
CLOUDINARY_CLOUD_NAME=
CLOUDINARY_API_KEY=
CLOUDINARY_API_SECRET=
```

### 5. Start Development Server

```bash
npm run dev
```

---

## Creating a Contribution

### Create a New Branch

```bash
git checkout -b feature/your-feature-name
```

### Commit Your Changes

```bash
git commit -m "Add: meaningful description"
```

### Push Changes

```bash
git push origin feature/your-feature-name
```

### Open a Pull Request

Submit a Pull Request describing your changes clearly.

---

## Contribution Guidelines

* Follow the existing code structure.
* Keep code clean and readable.
* Test your changes before submitting.
* Keep pull requests focused on a single feature or fix.
* Write meaningful commit messages.

---

## Areas for Contribution

* Frontend Improvements
* Backend Features
* UI/UX Enhancements
* Accessibility
* Documentation
* Performance Optimization
* Bug Fixes

## Reporting Issues

If you find a bug or want to request a feature:

1. Check existing issues first.
2. Create a new issue with a clear title.
3. Provide detailed information.
